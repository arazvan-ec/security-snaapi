# Functional Specs: previum-editorial-preview

> Phase 2 — WHAT the system must do
> Foundation: Shaped brief Requirements R0-R10

---

## SPEC-F01: JWT Token Extraction (R1)

**Description**: Extract Bearer JWT token from `Authorization` header.

**Acceptance Criteria**:
- [ ] Requests without `Authorization` header → `401`
- [ ] Requests with malformed header (not `Bearer <token>`) → `401`
- [ ] Requests with empty token → `401`

**Verification**: Unit tests with mock requests

---

## SPEC-F02: JWT Validation via External Microservice (R2)

**Description**: Validate extracted JWT by sending HTTP POST to external auth microservice.

**Acceptance Criteria**:
- [ ] SNAAPI sends client JWT to auth microservice via HTTP POST
- [ ] Non-2xx response from auth microservice → `401`
- [ ] Auth microservice unreachable (timeout/network error) → `401`
- [ ] Auth microservice URL configurable via environment variables

**Verification**: Unit tests with mocked HTTP client

---

## SPEC-F03: User Type Verification (R3, R5)

**Description**: Decode response JWT from auth microservice, verify `user_type === 'previum'`.

**Acceptance Criteria**:
- [ ] `user_type === 'previum'` → authentication succeeds
- [ ] `user_type !== 'previum'` → `403 Forbidden`
- [ ] Malformed response JWT → `401`

**Verification**: Unit tests with crafted JWTs

---

## SPEC-F04: Serve Unpublished Editorial Content (R0, R7, R8)

**Description**: Authenticated previum users access editorial content regardless of publication status.

**Acceptance Criteria**:
- [ ] Published editorials served normally
- [ ] Unpublished editorials (`isVisible() === false`) served instead of 404
- [ ] Non-existent editorials → `404`
- [ ] Response format identical to `/editorials/{id}`
- [ ] Response has NO public cache headers

**Verification**: Integration tests with mock editorial client

---

## SPEC-F05: Existing Endpoint Unaffected (R6)

**Description**: `GET /editorials/{id}` works exactly as before.

**Acceptance Criteria**:
- [ ] No authentication required
- [ ] Still returns 404 for unpublished editorials
- [ ] No performance impact
- [ ] Existing tests pass without modification

**Verification**: Run existing test suite unchanged

---

## SPEC-F06: Error Responses (R4, R5)

**Description**: Consistent JSON error responses.

**Acceptance Criteria**:
- [ ] `401`: `{"errors": ["Unauthorized"]}`
- [ ] `403`: `{"errors": ["Forbidden: insufficient permissions"]}`
- [ ] `404`: `{"errors": ["Editorial not published"]}`

**Verification**: Unit tests on response format
