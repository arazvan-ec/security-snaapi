## What We're Building

Un endpoint securizado `GET /previum/{editorialId}` que permite a usuarios con suscripción "previum" acceder a editoriales que aún no están publicados. La autenticación se delega a un microservicio externo vía HTTP, y solo usuarios con `user_type=previum` en el JWT de respuesta tienen acceso.

## Why It's Needed

Los editores y usuarios premium no tienen forma de previsualizar editoriales antes de publicación. El endpoint existente devuelve 404 para editoriales no publicados y no existe capa de autenticación.

## Who Benefits

- **Editores/Periodistas**: previsualización de contenido antes de publicación
- **Usuarios premium**: acceso anticipado a contenido
- **Producto**: funcionalidad de monetización

## Constraints

- **Technical**: Symfony Security stateless, HTTP client para validación externa
- **Security**: Control Level = HIGH (primera feature de auth)
- **Performance**: Timeout 3s para llamada HTTP al microservicio de auth
- **Backward Compatibility**: `/editorials/{id}` NO se modifica

## Success Criteria

(Derived from shaped brief R0-R10)

1. `GET /previum/{id}` sin token → `401 Unauthorized`
2. `GET /previum/{id}` con token inválido → `401 Unauthorized`
3. `GET /previum/{id}` con `user_type !== 'previum'` → `403 Forbidden`
4. `GET /previum/{id}` con `user_type === 'previum'` → editorial (publicado o no)
5. `GET /previum/{id}` editorial inexistente → `404 Not Found`
6. `GET /editorials/{id}` sigue igual (sin cambios)
7. PHPStan level 9 pasa
8. Mutation testing MSI >= 86%
